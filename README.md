## **Code Deck | An Online IDE**

### **Project Overview**
**Code Deck** is an online Integrated Development Environment (IDE) designed to provide users with a seamless platform to create, edit, and execute code snippets. Supporting multiple programming languages, theming options, and local storage for playgrounds, it is an excellent tool for coding enthusiasts, learners, and developers.

---

### **Features**
1. **Playground Management**: Create, edit, and save multiple code snippets with ease.
2. **Multi-Language Support**: Supports languages such as C++, Python, Java, and JavaScript for versatile coding needs.
3. **Interactive Code Editor**: Built with **ReactJS** using the **CodeMirror** package, offering syntax highlighting and a feature-rich editing experience.
4. **Responsive Layout**: Implemented with **styled-components**, ensuring a flexible and customizable user interface.
5. **Online Compilation**: Integrates the **Judge0 API** for seamless code execution.
6. **Theme Options**: Provides multi-theme support for a personalized coding experience.
7. **File Management**: Upload code files and download completed snippets for portability.
8. **Input/Output Console**: Allows uploading input files and downloading the output results.
9. **Local Storage Support**: Saves playgrounds locally for continued use and easy access.
10. **Fullscreen Mode**: Enables distraction-free coding with a fullscreen editor option.

---

### **Technologies Used**
- **Frontend**: React.js
- **Styling**: Styled Components
- **Compiler Integration**: Judge0 CE API (via Rapid API)
- **API Handling**: Axios
- **Routing**: React Router
